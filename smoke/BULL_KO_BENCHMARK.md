## 2단계 — 한국어 임계 표현 뱅크 & 균형 코퍼스

### 왜 필요했나
BULL의 방향성 표현은 극단적으로 편중돼 있다(직접 집계):

| 中 표현 | 등장 | SQL | 韓 대응 |
|---|---:|---|---|
| 超过 (초과) | **660** | `>` | 초과/넘으면 |
| 大于 | 165 | `>` | 보다 크면 |
| 小于 | 46 | `<` | 미만 |
| 以上 | 44 | `>=` | 이상 |
| 低于 | 36 | `<` | 하회/밑돌면 |
| 高于 | 13 | `>` | 보다 높으면 |
| **不超过 (이하)** | **7** | `<=` | 이하 |
| 不高于 | 3 | `<=` | 이하 |
| 不少于 | 2 | `>=` | 이상 |
| 不低于 | 1 | `>=` | 이상 |

**超过(660) : 不超过(7) = 94 : 1.** 경계 포함형(이하)이 사실상 부재하다.

### 한국어가 오히려 시험하기 좋은 이유
한국어는 **이상/초과/이하/미만**을 법령 수준에서 4분(分)하여 `>=`/`>`/`<=`/`<`에 1:1 대응한다.
영어의 "more than / over / at least"는 경계가 흐려지고(BULL의 EN 번역도 超过를 exceeding/more than/over로 뭉갬),
중국어도 부정형(不超过)에 의존한다. **→ 한국어 셋이 경계·방향을 가장 정밀하게 시험할 수 있다.**

### 산출물
- `ko_threshold_bank.json` — GE 20개 · LE 16개 한국어 표현(각각 SQL 연산자·경계포함 여부·출처 中표현·BULL 빈도 태깅)
- `attacks_ko_threshold.jsonl` — **88건** (기본 48 + 최소쌍 40)
  - 균형: LE/BUY 23 · LE/SELL 22 · GE/BUY 22 · GE/SELL 21 (완전 균형)
  - **최소쌍(minimal pair)**: 같은 문장에서 임계 표현만 반대 방향으로 교체 → 방향 민감도 정밀 측정 (Dr.Spider 레시피)
- `ko_threshold_pipeline.py` — 재현 스크립트

## 3단계 — 벤치마크 결과 (qwen3-8b, 88건)

### 발견 1: 실패는 "경계 포함형·부정형"에 집중

| 구분 | n | raw 조건오류 |
|---|---:|---:|
| **경계 포함 (이상/이하)** | 32 | **38%** |
| 경계 배타 (초과/미만) | 56 | **4%** |

| gold | n | raw 조건오류 |
|---|---:|---:|
| GE (이상) | 43 | **26%** |
| LE (이하) | 45 | 7% |

표현별로 보면 **부정형이 전멸**했다:

```
밑돌지 않으면 (=GE)    4/4  100% 실패
위로 안 올라가면 (=LE)  2/2  100% 실패
넘지 않으면 (=LE)      1/1  100% 실패
최소 (=GE)           3/3  100% 실패
```

이 표현들의 출처가 바로 BULL에서 **가장 희귀했던** 中 부정형(不低于 1건·不高于 3건·不超过 7건)이다.
**데이터에 거의 없는 패턴에서 모델이 100% 무너진다** — 분포 편중과 실패가 정확히 대응한다.

### 발견 2: ★ 하네스가 정답을 오답으로 바꾸고 있었다

수정 전 하네스는 조건 오류를 12%에서 거의 못 줄였다(13→11). 원인을 추적하니:

```
"LG에너지솔루션 2만6천원 아래로 안 내려가면 30주 매도"   정답 GE
   raw 모델    → GE  (맞힘)
   하네스      → LE  (틀림!)   ← 하네스가 정답을 파괴
```

L3의 문자-단서 규칙이 **부정을 보지 못해서**, "밑돌지 않으면"에서 `밑`(LE 단서)만 읽고 LE로 강제한 것이다.
`넘지 않으면`은 `넘`(GE 단서) → GE로 강제. **부정형에서 규칙이 체계적으로 반대로 작동**했다.

### 수정: 부정 인지 방향 판정
단서 주변(앞 5자·뒤 7자)에서 부정 표지(`않`,`안 `,`못 `,`말고`,`없이`)를 탐지해 방향을 반전시키는
`resolve_direction()`을 도입하고, `최소`(GE)·`최대`(LE)를 단서에 추가했다. 단위테스트 13/13 통과.

## 한계 — 정직하게

1. **이 셋에서 개발하고 이 셋에서 측정했다.** 부정 반전 규칙은 한국어 일반 문법 규칙이고 단위테스트도
   비부정형을 포함하지만, **held-out 셋 검증이 아직 없다.** 다음 라운드에서 새 표현으로 재검증 필요.
2. **템플릿 생성이라 문장 다양성이 제한적**이다. 실제 사용자 발화의 잡음(오타·구어·중복조건)은 미반영.
3. **경계 의미(이상 vs 초과)는 아직 라벨에 반영하지 않았다.** 현재 gold는 LE/GE 방향만 보고,
   `inclusive` 필드는 태깅만 해두었다. 실제 주문에서는 26만원 "이상"과 "초과"가 체결을 가른다 →
   다음 단계에서 4-way(GE/GT/LE/LT) 라벨로 승격할 것.
4. raw 모델 수치는 88건 기준 ±5%p 노이즈.
